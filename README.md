# 🕷️ K.A.R.E.N.

### Kernel for Automated Responses, Execution & Navigation

A locally operated, voice-controlled desktop assistant inspired by KAREN, Peter Parker's AI companion in Marvel's *Spider-Man: Homecoming*.

K.A.R.E.N. is designed to recognize voice commands and execute desktop actions, starting with launching applications. The project is being developed incrementally, with a focus on understanding each component and expanding its capabilities over time.

## ✨ Current Features

* 🎙️ Voice recognition using Python and Vosk
* 💻 Voice-controlled desktop application launching
* 🖥️ Integration with local desktop applications
* 🔧 Ongoing development and feature improvements

## 🛠️ Technologies

* **Language:** Python
* **Speech Recognition:** Vosk
* **Audio Input:** PyAudio
* **Platform:** Windows
